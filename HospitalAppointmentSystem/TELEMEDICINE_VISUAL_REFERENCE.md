## 🎨 **COLOR SCHEME**

### Navigation Bar (Top)
- **Background**: Dark Blue (#00547E)
- **Text**: White
- **Buttons**: Medium Blue (#006699) → Lighter Blue (#0078B4) on hover

### Status Bar (Bottom)
- **Background**: Light Blue-Gray (#DCE6F0)
- **Status Label**: Dark Slate Gray
- **Connection Indicator**:
  - 🟢 Green: Online/Connected
  - 🔴 Red: Offline/Error
  - ⚫ Gray: Initializing/Unavailable

### Landing Page (WebView2 Content)
- **Background**: Purple Gradient (#667EEA → #764BA2)
- **Container**: Translucent White (rgba(255, 255, 255, 0.1))
- **Text**: White
- **Instructions Box**: Translucent White (rgba(255, 255, 255, 0.2))

### Error Fallback
- **Background**: Light Cream (#FFFAF0)
- **Icon**: Red ✖️
- **Title**: Dark Red
- **Text**: Dark Slate Gray
- **Buttons**: Green (Retry), Red (Return)

## 🖱️ **BUTTON BEHAVIORS**

### Top Navigation Buttons

| Button | Icon | Action | Tooltip |
|--------|------|--------|---------|
| **◄ Back** | ◄ | webView.CoreWebView2.GoBack() | Navigate to previous page |
| **🔄 Refresh** | 🔄 | webView.CoreWebView2.Reload() | Reload current page |
| **🏠 Home** | 🏠 | ShowTelemedicineLandingPage() | Return to landing page |
| **Go ►** | ► | NavigateToMedicalPortal(url) | Navigate to entered URL |

### Mouse Hover Effects
- **Buttons**: Lighten background color by 15%
- **URL Bar**: Subtle blue border glow
- **Cursor**: Changes to hand pointer (Cursors.Hand)

## 🔐 **SECURITY INDICATORS**

### HTTPS-Only URLs
```
✅ https://meet.jit.si/RoomName          (ALLOWED)
✅ https://medicare-hospital.daily.co/   (ALLOWED)
✅ https://zoom.us/j/123456789            (ALLOWED)
❌ http://example.com                     (BLOCKED)
❌ not-a-valid-url                        (REJECTED)
```

### URL Bar Visual Feedback
- **Valid HTTPS**: Green border glow
- **Invalid HTTP**: Red border + error dialog
- **Invalid Format**: Orange border + warning

## 📱 **RESPONSIVE DESIGN**

### Minimum Window Size
- **Width**: 1024 pixels
- **Height**: 768 pixels

### Maximized State
- **WebView2**: Expands to fill available space (Dock=Fill)
